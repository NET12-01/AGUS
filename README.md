# AGUS · Asistente personal 9.0

Asistente personal inspirado en J.A.R.V.I.S. (Marvel) con:
- Personalidad de mayordomo británico: formal, elegante, ingenio seco
- Obediencia total a personalización de nombre/apelativo
- Apertura rápida de sitios + búsqueda dentro (YouTube, Google, etc.)
- Cambio de color del reactor en tiempo real (10 colores)
- Voz 100% masculina con pitch grave
- Matemática avanzada (primos, factoriales, Fibonacci, estadísticas, cuadráticas)
- 200+ respuestas locales (chistes, curiosidades, historia, ciencia, etc.)
- IA opcional con búsqueda web

## Requisitos
- Node.js 20+
- Chrome/Edge/Safari
- Clave OpenAI (opcional)

## Inicio
1. Doble clic en `INICIAR_AGUS.bat`
2. Editar `.env` con `OPENAI_API_KEY=sk-...`
3. Abrir http://127.0.0.1:3000

## Comandos
Ver la sección Ayuda dentro de la app (decir "ayuda").

## Protección
- Clave API solo en servidor
- Escucha en 127.0.0.1
- Rate limit 30 msgs / 10 min
